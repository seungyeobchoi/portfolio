# 검증 결과와 남은 범위

진행상황 검토·문서 갱신일은 2026-10-07입니다. 아래는 보존된 작업·검증 기록과 사용자 확인을 요약한 것으로 실시간 상태 조회가 아닙니다. 검토일, 문서 편집·정리일과 실제 실행 검증일을 구분합니다. 기록의 제목·검증 항목 이름이나 잘린 로그만으로 성공을 판정하지 않습니다.

## 후속 작업과 아직 확인되지 않은 결과

| 대상 | 검토한 후속 작업·설계 | 다음에 확인할 결과 |

| 포털 worker | FBS 단일 replica 활성화·상태 조정(reconciliation), Dispatcher 활성화·2 replica 작업, 다중 replica 준비 상태 진단 | 역할별 실행 결과와 모든 worker의 다중 replica 검증 |

| 챗봇 연결 | Gateway·모델·애플리케이션·외부 AI DB 설계와 통합 작업 | 포털 요청부터 모델 응답까지의 전체 흐름, 실제 DB 연동과 배포 후 동작 |
| 모델·검색 구성 | 8월 26일 vLLM·Qwen3, pgvector·HNSW, RAG·Rule Engine·MCP 후보·구성 검토 | 최종 적용 구성과 실제 서빙·성능·품질 검증 |

10월 7일 검토에서는 위 후속 작업의 최종 실행 성공을 추가로 확인하지 못했습니다. 작업 진행 기록을 중단 상태로 해석하지도, 문서 정리일을 새로운 성공일로 해석하지도 않습니다. 과거 특정 시점의 FBS·Dispatcher replica 수는 현재 배포 상태를 입증하지 않습니다. 단일 GPU 물리 노드 장애에 대한 고가용성도 확인 범위에 포함하지 않습니다.

## 검증 접근과 기여 범위

리소스가 생성됐다는 사실만으로 서비스 완료로 판단하지 않고, 상태·통신·스토리지 I/O와 삭제 후 자원 회수까지 확인한 범위를 구분합니다. 로그와 설정을 대조하고, 조회 실패 하나만으로 특정 원인을 확정하지 않습니다.

본인은 서비스 전체 구조, 포털 연계, GPU Kubernetes·네트워크·스토리지와 외부 데이터 인프라 설계·통합 및 문제 해결·검증을 담당합니다. 협업 구성원 1명은 LLM 관련 설계를 담당하며, 포털 API/Worker 코드 작성에는 AI의 도움을 받았습니다.

## 공개 범위

실제 IP·호스트명·계정·인증자료, 원본 운영 출력, 비공개 원문 링크와 실행 가능한 운영 설정은 제외했습니다. 구조도는 접속 안내가 아니라 역할과 설계 판단을 설명하기 위한 요약입니다. 계정이나 주소를 제거했다는 사실만으로 모든 자료의 공개 권한을 보장하지는 않습니다.
