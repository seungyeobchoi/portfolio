## 구현과 설계 구분

구축·검증한 기반 위에 Kubernetes 사용자 서비스 통합과 GPU 챗봇 연동을 진행 중입니다. AI DB의 외부 배치, 챗봇 Gateway와 모델·애플리케이션 연결은 설계와 실제 적용 상태를 분리해 기록합니다.

## 검증 접근

리소스가 생성됐다는 사실만으로 서비스 완료로 판단하지 않고, 상태·통신·스토리지 I/O와 삭제 후 자원 회수까지 확인한 범위를 구분합니다. 로그와 설정을 대조하고, 조회 실패 하나만으로 특정 원인을 확정하지 않습니다.

## 공개 범위

실제 IP·호스트명·계정·인증자료, 원본 운영 출력과 실행 가능한 운영 설정은 제외했습니다. 구조도는 접속 안내가 아니라 역할과 설계 판단을 설명하기 위한 요약입니다. 계정이나 주소를 제거했다는 사실만으로 모든 자료의 공개 권한을 보장하지는 않습니다.
